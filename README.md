# Northstar Studio — Personal Business Website

A responsive, accessible business website for DecodeLabs Full Stack Development Project 1.

## Technology
- Semantic HTML5
- CSS3 (Grid, Flexbox, media queries, fluid typography)
- Vanilla JavaScript (mobile navigation, validation, current year)
- No frameworks or build tools

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Resize the browser or use device emulation to test mobile (<768px), tablet (768–1023px), and desktop (1024px+).

## Files
- `index.html` — page structure and content
- `css/style.css` — visual styling and responsive layouts
- `js/script.js` — menu and form behavior

## Customize for your business
1. Replace **Northstar Studio** with your business name in `index.html` and update the page title and meta description.
2. Edit About, Services, Process, and project examples to reflect your actual work. The two portfolio examples are **fictional concepts**, not real clients.
3. Add your business contact details and links where appropriate.
4. The contact form is **frontend-only** and does not transmit messages. Connect a backend or form handling service before using it for real customer inquiries.
5. Fonts load from Google Fonts if internet access is available; fallback system fonts work offline.

## Suggested checks before submission
- Check navigation, links, validation, and keyboard tab order.
- Check at 375px, 768px, 1024px, and 1440px widths.
- Run Lighthouse for accessibility, LCP, and CLS. No score is claimed without testing.
- Check semantic landmarks and color contrast.

## Assignment alignment
Discovery and wireframe planning, semantic HTML, CSS Grid/Flexbox, mobile-first layout, basic JavaScript interaction, and accessibility/performance review. No frameworks used.
